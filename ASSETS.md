# Image sources

The redesign uses photographs, not generated images.

- `assets/photos/`: downloaded from public posts on the owner's `https://www.instagram.com/lukaah.photography/` profile. Individual source post links, descriptions, and local paths are in `assets/photography.json`. Exports are compressed WebP copies with no generative alteration. Images were selected from the public profile on 2026-09-15.
- `assets/projects/sunken.webp`: the existing Sunken Freediving site image at `public/images/site/hero-home.jpg` in the user's Sunken project.
- `assets/projects/emily.webp`: the existing portrait at `assets/founder.jpg` in the user's Emily Marlowe project.
- `assets/projects/flowers.webp`: the live Flowers on 5th image at `https://flowerson5th.co/hero-flowers.jpeg`.

Older portfolio assets remain in Git for history but are not referenced by the redesigned page. The project panels are graphic links using the sites' photographs and names, not screenshots of their interfaces.
